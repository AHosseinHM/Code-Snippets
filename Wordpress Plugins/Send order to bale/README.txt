JALDIO Order File to Bale

نصب:
1. فایل ZIP افزونه را در وردپرس از مسیر افزونه‌ها > افزودن > بارگذاری افزونه نصب کنید.
2. افزونه را فعال کنید.
3. از مسیر تنظیمات > JALDIO بله، توکن ربات و Chat ID را بررسی/ویرایش کنید.
4. در المنتور، برای دکمه موردنظر در بخش CSS Classes این کلاس را قرار دهید:
   send-order

فرمت‌های مجاز:
PDF, JPG, JPEG, PNG

حداکثر حجم فایل:
10MB
